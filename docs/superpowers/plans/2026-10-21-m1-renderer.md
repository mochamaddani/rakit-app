# M1 Renderer-First Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure, deterministic `renderPage(doc, { mode })` that turns a validated PageDocument into one self-contained HTML file. It ships with five core blocks and the Product Carousel special component, snapshot and safety tests, a render CLI, and browser tests proving the carousel works with and without JavaScript.

**Architecture:**
- The document schema is built from a block registry. Each block is one folder holding a Zod schema, a pure `render(props, ctx) → SafeHtml`, a static stylesheet, and an optional vanilla snippet.
- Stylesheets and snippets are real `.css`/`.js` files that esbuild compiles into committed `*.generated.ts` modules. The renderer therefore stays free of build tools and runs in both Node and the browser.
- All markup is built with an escaping `html` template tag. Per-instance options travel as CSS custom properties, so the page's CSS depends only on which block types are present.

**Tech Stack:** TypeScript 5 (strict), Zod 4.6.7, esbuild 0.28.2, tsx 4.23.15, Vitest 5.0.5 (+ file snapshots, `expectTypeOf`), html-validate 11.17.0, happy-dom 21.0.4, Playwright 1.64.1.

**Spec:** `docs/PRD.md` §5.1–5.3, §6.3–6.4.1, §8, §10 (M1), with decisions in `docs/PLAN.md` and `docs/DECISIONS.md` (D-009…D-018, D-028, D-029).

## Global Constraints

- **Renderer purity:** no DOM access, no I/O, no `Date`, `Math.random` or `Intl` inside `lib/renderer` or `lib/blocks`. The same document always produces the same bytes.
- **Markup safety:** every piece of markup comes from the `html` tag.
  - Text goes through `ctx.text()` (plain) or `ctx.rich()` (inline markup).
  - Every `href` goes through `ctx.resolveLink()` or `renderCta()`; every `src` through `renderImage()` / `sanitizeUrl()`.
  - `unsafeRaw()` is only for generated CSS/JS and icon SVG constants.
- **Output shape:** exactly one `<style>`, at most one `<script>`, no external requests, no framework code. The HTML must pass `html-validate:recommended`; the only rule disabled is `no-inline-style`, because custom properties are intentional (D-012).
- **Breakpoints:** mobile-first; tablet `@media (min-width: 640px)`, desktop `@media (min-width: 1024px)`. Container side gutter 16 px (24 px at ≥ 640 px).
- **Naming:** class prefix `lp-`. Block wrapper id `b-<blockId>`. Section id is the `anchor`, or `s-<sectionId>`. Ids for inner elements come from `ctx.domId(…)` (`b-<blockId>-…`).
- **Settings defaults:** `lang` defaults to `'id'`, `seo.noindex` to `true`, prices to `IDR` (`Rp149.000`).
- **Product Carousel requirements:**
  - Built on CSS scroll-snap (`overflow-x: auto; scroll-snap-type: x mandatory`) and works without JS.
  - Snippet ≤ **1536 bytes** minified. Several carousels on one page stay independent.
  - Accessibility: a labelled `<section>` (role region) with `aria-roledescription="carousel"`; slides use `role="group"` + `aria-roledescription="slide"`; arrows, Home and End work from the keyboard.
  - Images: the first `ceil(slidesPerView.mobile)` load eagerly (the first with `fetchpriority="high"`) only when the carousel is above the fold; all images carry explicit width/height plus `aspect-ratio`.
  - Default slides per view: mobile 1.3, tablet 2.5, desktop 4.
- Base CSS ≤ **4096 bytes** minified.
- **Zod 4:** use `.prefault(x)` (not `.default(x)`) on nested objects whose fields have defaults, because `.default` short-circuits and skips inner defaults. All user-visible strings use the `text(max, min?)` / `rich(max, min?)` helpers.
- **Defaults never fabricate social proof:** default testimonials use `[REPLACE: …]` placeholders (PRD §6.11).
- **Adding a block** touches only its folder plus one line in `BLOCKS`. Unit tests sit next to the code; snapshots live in `__snapshots__/` as `.html` files.

## Review Focus

Failure modes the spec implies but feature tests would not naturally exercise. Each one is pinned by the named test.

1. **Hostile text or URLs in any field of any block** (XSS through a forgotten escape or an unsanitized `href`). Expect: shown as inert text, with `href`/`src` neutralized. Test: `escapes hostile text and neutralizes hostile URLs in every field` (Task 11, registry-wide).
2. **Blocks with only required fields** (empty optional strings, empty lists, missing images). Expect: valid HTML, no empty wrappers that break layout. Tests: `renders valid HTML with only required fields` in each block task, and `renders valid HTML from its default props` (Task 11).
3. **Long unbroken words or URLs on a 360 px phone.** Expect: no horizontal page scroll. Test: `no horizontal overflow at 360px width` (Task 12).
4. **Duplicate ids** from copy-paste or AI output (two blocks or two items sharing an id). Expect: `parseDocument` rejects them with the exact path, because they would collide in DOM ids and carousel scoping. Tests: `rejects duplicate block ids across sections` and `collectIdIssues finds duplicate ids inside item lists` (Task 5).
5. **Two carousels on one page.** Expect: controls and active state never leak between them. Tests: `two carousels are independent` (Task 12) and `scopes ids and data attributes by block id` (Task 9).

### Task 2: HTML safety and text utilities

**Files:**
- Create: `lib/renderer/html.ts`, `lib/renderer/url.ts`, `lib/renderer/inline.ts`, `lib/renderer/format.ts`, `lib/renderer/i18n.ts`
- Test: `lib/renderer/html.test.ts`, `lib/renderer/url.test.ts`, `lib/renderer/inline.test.ts`, `lib/renderer/format.test.ts`, `lib/renderer/i18n.test.ts`

**Interfaces:**
- Consumes: `PriceFormat`, `Lang` (Task 1).
- Produces:
  - `html.ts`:
    - `class SafeHtml { readonly value: string; toString(): string }`
    - `type HtmlValue = SafeHtml | string | number | boolean | null | undefined | readonly HtmlValue[]`
    - `html(strings: TemplateStringsArray, ...values: HtmlValue[]): SafeHtml`. Strings and numbers are escaped; `SafeHtml` is inserted as-is; `null`, `undefined` and booleans render nothing; arrays are flattened.
    - `escapeHtml(text: string): string` escapes `& < > " '` as `&amp; &lt; &gt; &quot; &#39;`.
    - `unsafeRaw(markup: string): SafeHtml`
    - `byteLength(text: string): number` (UTF-8)
    - `escapeInlineScript(code: string): string` replaces `</script` (any case) with `<\/script` and `<!--` with `<\!--`.
    - `escapeInlineStyle(css: string): string` replaces `</style` (any case) with `<\/style`.
  - `url.ts`: `sanitizeUrl(input: string, kind: 'link' | 'image'): string | null`.
    - Trims the input, then rejects it if any ASCII control or whitespace character sits before the first `:`.
    - Link schemes: `http`, `https`, `mailto`, `tel`, `sms`, plus scheme-less `#…`, `/…`, `?…`.
    - Image schemes: `http`, `https`, scheme-less paths, and `data:image/(png|jpeg|webp|gif|avif|svg+xml)`.
    - Anything else returns `null`.
  - `inline.ts`:
    - `interface InlineOptions { highlightPlaceholders: boolean }`
    - `PLACEHOLDER_PATTERN = /\[REPLACE:[^\]]*\]/g`
    - `findPlaceholders(text: string): string[]`
    - `renderInline(text: string, opts: InlineOptions): SafeHtml` (markup subset per D-009)
    - `renderText(text: string, opts: InlineOptions): SafeHtml` (escape only, plus placeholder highlight)
    - `toPlainText(text: string): string` (strips markup, keeps link labels, newline → space)
  - `format.ts`:
    - `formatPrice(amount: number, format: PriceFormat): string`. Uses `toFixed(decimals)`, then inserts the thousands separator.
    - `discountPercent(price?: number, compareAt?: number): number | null`. Returns `Math.round((1 - price / compareAt) * 100)` when `0 < price < compareAt` and the result is ≥ 1; otherwise `null`.
    - `formatDecimal(value: number, lang: Lang): string`. Rounds to 1 decimal; integers print without decimals; `id` uses `,` as the decimal separator.
  - `i18n.ts`:
    - `type MessageKey = 'products' | 'prevSlide' | 'nextSlide' | 'goToSlide' | 'slideLabel' | 'rated' | 'reviews' | 'originalPrice' | 'links' | 'untitled'`
    - `t(lang: Lang, key: MessageKey, vars?: Record<string, string | number>): string`

| key | id | en |
|---|---|---|
| products | Produk | Products |
| prevSlide | Slide sebelumnya | Previous slide |
| nextSlide | Slide berikutnya | Next slide |
| goToSlide | Ke slide {n} | Go to slide {n} |
| slideLabel | {n} dari {total} | {n} of {total} |
| rated | Rating {rating} dari 5 | Rated {rating} out of 5 |
| reviews | {count} ulasan | {count} reviews |
| originalPrice | Harga normal | Original price |
| links | Tautan | Links |
| untitled | Tanpa judul | Untitled |

Inline markup rules:
- `**bold**` → `<strong>`, `*italic*` → `<em>`, `==highlight==` → `<mark class="lp-hl">`, `[label](url)` → `<a href>` (label escaped; URL through `sanitizeUrl(…, 'link')`; an unsafe URL leaves only the label text), newline → `<br>`, `\*` `\=` `\[` `\\` → literal characters.
- Markers must touch the enclosed text: no space just inside a marker. Unmatched markers stay literal. There is no nesting except marks inside link labels.
- `[REPLACE: …]` placeholders render as `<mark class="lp-replace">…</mark>` only when `highlightPlaceholders` is true.

```ts
import { describe, expect, it } from 'vitest';
import { byteLength, escapeInlineScript, escapeInlineStyle, html, unsafeRaw } from '@/lib/renderer/html';

describe('html tag', () => {
  it('escapes interpolated strings, including quotes for attribute context', () => {
    const v = `"><script>alert(1)</script>'`;
    expect(String(html`<p title="${v}">${v}</p>`)).toBe(
      '<p title="&quot;&gt;&lt;script&gt;alert(1)&lt;/script&gt;&#39;">&quot;&gt;&lt;script&gt;alert(1)&lt;/script&gt;&#39;</p>',
    );
  });
  it('inserts SafeHtml unescaped and flattens arrays', () => {
    const items = ['a', 'b'].map((x) => html`<li>${x}</li>`);
    expect(String(html`<ul>${items}${unsafeRaw('<li>c</li>')}</ul>`)).toBe('<ul><li>a</li><li>b</li><li>c</li></ul>');
  });
  it('renders null, undefined and booleans as nothing, numbers as text', () => {
    expect(String(html`<p>${null}${undefined}${false}${true}${0}</p>`)).toBe('<p>0</p>');
  });
  it('counts UTF-8 bytes', () => {
    expect(byteLength('Rp✓')).toBe(5);
    expect(byteLength('😀')).toBe(4);
  });
  it('neutralizes closing tags inside inline scripts and styles', () => {
    expect(escapeInlineScript('a</SCRIPT>b<!--c')).toBe('a<\\/SCRIPT>b<\\!--c');
    expect(escapeInlineStyle('a</style>b')).toBe('a<\\/style>b');
```

`lib/renderer/inline.test.ts`:

```ts
import { describe, expect, it } from 'vitest';
import { findPlaceholders, renderInline, renderText, toPlainText } from '@/lib/renderer/inline';

const plain = { highlightPlaceholders: false };

describe('inline markup', () => {
  it('formats bold, italic, highlight and line breaks', () => {
    expect(String(renderInline('**Hemat** *hari ini* ==50%==\nSaja', plain))).toBe(
      '<strong>Hemat</strong> <em>hari ini</em> <mark class="lp-hl">50%</mark><br>Saja',
    );
  });
  it('renders safe links and drops unsafe ones to their label', () => {
    expect(String(renderInline('[Pesan](https://wa.me/62812)', plain))).toBe('<a href="https://wa.me/62812">Pesan</a>');
    expect(String(renderInline('[Klik](javascript:alert%281%29)', plain))).toBe('Klik');
  });
  it('escapes HTML in every position', () => {
    expect(String(renderInline('<b>x</b> **<i>y</i>** [<img>](https://a.b/"x)', plain))).toBe(
      '&lt;b&gt;x&lt;/b&gt; <strong>&lt;i&gt;y&lt;/i&gt;</strong> <a href="https://a.b/&quot;x">&lt;img&gt;</a>',
    );
  });
  it('supports backslash escapes and leaves unmatched markers literal', () => {
    expect(String(renderInline('5\\*4 = 20', plain))).toBe('5*4 = 20');
    expect(String(renderInline('**unclosed and * lone', plain))).toBe('**unclosed and * lone');
  });
  it('highlights [REPLACE: …] placeholders only when asked', () => {
    const t = 'Harga [REPLACE: harga promo]';
    expect(String(renderInline(t, { highlightPlaceholders: true }))).toBe('Harga <mark class="lp-replace">[REPLACE: harga promo]</mark>');
    expect(String(renderInline(t, plain))).toBe('Harga [REPLACE: harga promo]');
    expect(String(renderText('[REPLACE: x]', { highlightPlaceholders: true }))).toBe('<mark class="lp-replace">[REPLACE: x]</mark>');
  });
  it('renderText escapes but never interprets markup', () => {
    expect(String(renderText('**Rp**<b>', plain))).toBe('**Rp**&lt;b&gt;');
  });
  it('toPlainText strips markup and keeps link labels', () => {
    expect(toPlainText('**Hemat** [di sini](https://x.y) ==50%==\nyes')).toBe('Hemat di sini 50% yes');
  });
  it('findPlaceholders lists every placeholder', () => {
    expect(findPlaceholders('[REPLACE: a] x [REPLACE: b]')).toEqual(['[REPLACE: a]', '[REPLACE: b]']);
  });
});
```

      - A missing `schemaVersion` counts as 0.
      - Throws `DocumentValidationError` for: non-object input; a version above the target (message contains `newer`); a missing step (message `no migration from version <n>`).
      - Never mutates its input.

    - `BlockInstanceSchema`: a discriminated union on `type`, with one `z.object({ id: IdSchema, type: z.literal(def.type), props: def.schema, style: BlockStyleSchema.prefault({}) })` per registry entry.

    - `collectIdIssues(doc: unknown): DocumentIssue[]`. Section ids and block ids must be unique across the whole document; `id`s of objects inside any props array must be unique within that array. Message: `Duplicate id "<id>"`, reported at the later occurrence's `.id` path.
    - `parseDocument(raw: unknown): PageDocument` (migrate, then validate; throws `DocumentValidationError`)
    - `safeParseDocument(raw: unknown): { ok: true; doc: PageDocument } | { ok: false; error: DocumentValidationError }`

- Create: `lib/blocks/special/product-carousel/snippet.js`, `lib/blocks/special/product-carousel/snippet.generated.ts` (generated)
- Modify: `lib/blocks/special/product-carousel/index.ts`, `lib/blocks/special/product-carousel/product-carousel.test.ts`

**Interfaces:**
- Consumes: `collectJs` (Task 6), carousel markup (Task 9).
- Produces: `productCarousel.snippet = { asset, isNeeded: (p) => p.navigation !== 'none' && p.items.length > 1 }`.

Behavior of `snippet.js` (vanilla ES2017, no globals; esbuild wraps it in an IIFE):
- For every `[data-lp-carousel]` root without `data-lp-ready`, set `data-lp-ready`. Find its own track, slides, `[data-lp-prev]`, `[data-lp-next]` and `[data-lp-dot]`. Query only inside the root, so carousels never interact. Remove `hidden` from its `.lp-carousel__nav`.
- **Current index:** the slide whose `offsetLeft - slides[0].offsetLeft` is nearest to `track.scrollLeft`; when the track is scrolled to the end (`scrollLeft + clientWidth >= scrollWidth - 2`), use the last index. Recompute on `scroll` (passive, one `requestAnimationFrame` per frame).
- **On update:** each dot gets `aria-current="true"` if it is current, otherwise `"false"`. When `data-loop` is `"0"`, `prev.disabled` at index 0 and `next.disabled` at the end.
- **`go(i)`:** with loop on, wraps around; otherwise clamps. Calls `track.scrollTo({ left: slides[i].offsetLeft - slides[0].offsetLeft, behavior })`, where `behavior` is `'auto'` under `prefers-reduced-motion: reduce` and `'smooth'` otherwise.
- **Events:** prev/next call `go(current ∓ 1)`; dot *i* calls `go(i)`. On the track, `keydown` maps `ArrowLeft`/`ArrowRight` → `go(current ∓ 1)`, `Home` → `go(0)`, `End` → `go(last)`, each with `preventDefault()`.
