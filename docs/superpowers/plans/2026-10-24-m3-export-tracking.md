# M3 Export + Tracking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page built in the editor, with its order form (Storelink embed code or an iframe form), downloads as one self-contained `<slug>.html` that fires PageView, CTA events and `Lead` to Meta Pixel, Google tag/GA4/Ads and GTM, passes UTM and click ids to CTAs and the form, embeds an external form, and is recorded as an immutable version that can be restored in one click.

**Architecture:**
- **Renderer stays pure.** Page settings gain SEO extras and tracking ids. `renderPage(doc, { mode: 'export', tracking })` emits vendor tags, custom snippets and a small page runtime (`lib/tracking/snippet.js`) only in export mode; preview never carries third-party code (Plan §2.10).
- **Events go through one dispatcher.** The page runtime listens for a `lp:track` DOM event and calls `fbq`/`gtag`/`dataLayer` with one `event_id` per event (D-021). CTAs carry `data-lp-event`; the Form Embed snippet turns a provider's submit message into `lp:track` `Lead`. The same runtime appends incoming UTM and click ids to outbound CTA links and form iframes.
- **Export runs in the browser** (D-007): `buildExport` turns the document into an export copy (Portable: images fetched and inlined as data URIs; favicon rasterized), renders it, hashes it and builds the size report and checklist. The dialog downloads the bytes, then uploads them to the private `page-versions` bucket and calls one RPC that inserts the `page_versions` row and moves the page to `exported`.
- **Rollback is an editor command** (`restoreDocument`), so it is undoable and saved by autosave like every other edit.

**Tech Stack:** Next.js 16.4.2 (App Router), React 19.3, TypeScript 5 (strict), Zustand 5.0.15, Immer 11.1.21, Zod 4.6.7, Supabase (Postgres, Storage, RLS; `@supabase/ssr` 0.12.7, `@supabase/supabase-js` 2.118.0), shadcn/ui 4 (Base UI), lucide-react, esbuild 0.28.2, Vitest 5.0.5 (+ happy-dom), Playwright 1.64.1, html-validate 11, pgTAP. No new dependencies.

## Global Constraints

- **Node 24 on every command:** prefix `pnpm`/`node` with `export PATH="$HOME/.nvm/versions/node/v24.22.1/bin:$PATH";`.
- **Next.js 16:** read the relevant guide in `node_modules/next/dist/docs/` before using an API. Route handler context is `RouteContext<'/path'>`, page props `PageProps<'/path'>`, and `params` are Promises.
- **Auth on every entry point:** server actions and pages call `requireUser()` first; route handlers call `getApiUser()` and return `unauthorizedResponse()` on `null`. Browser Supabase calls run as the signed-in user, so RLS and storage policies apply. The service-role key appears only in `tests/e2e/**` and `scripts/**`.
- **Renderer purity:** no `Date`, `Math.random`, `Intl` or I/O in `lib/renderer`, `lib/blocks` or `lib/tracking/*.ts`. Same document and options → same bytes. Event ids are generated by the exported page's own JavaScript at view time, never by the renderer.
- **Preview carries no third-party code:** in `mode: 'preview'` the output has no vendor tags, no custom snippets, no page runtime and no form iframe or snippet (Plan §2.10). A test pins this.
- **Exported HTML never runs on the editor origin** (D-022). It is downloaded through `<a download>` from a Blob, copied as text, or stored in Storage; it is never shown in an iframe without `sandbox`, never opened as a `blob:` URL in a tab, and never served by an app route.
- **Owner-supplied raw code** (custom head/body snippets, Form Embed snippet mode) is emitted verbatim in export only, never in preview, and always named by the pre-export checklist. Everything else still goes through the `html` tag (D-010).
- **Exact numbers:**
  - Size budget: warn above 1,000,000 bytes, hard-warn above 3,000,000 bytes (decimal MB, as shown to the user); a single image over 300,000 bytes is "large".
  - Page runtime (`lib/tracking/snippet.js`) ≤ 2048 bytes minified; Form Embed snippet ≤ 1024 bytes minified. Carousel stays ≤ 1536.
  - Passed-through parameters: every `utm_*` key plus `gclid`, `fbclid`, `wbraid`, `gbraid`; at most 20 keys, values at most 500 characters.
  - Portable mode inlines the 800 px WebP variant of uploaded assets (D-046). Favicons are rasterized to a 64×64 PNG.
  - After a detected form submit with a thank-you URL, the page waits 500 ms, then navigates.
  - `page-versions` bucket: private, 20 MiB per object (20,971,520 bytes), `text/html` only. The versions list shows the newest 50.
  - Tracking id formats (empty string allowed): Meta Pixel `^\d{10,20}$`, GA4 `^G-[A-Z0-9]{4,16}$`, Google Ads `^AW-\d{6,16}$`, Ads conversion label `^[A-Za-z0-9_-]{4,64}$`, GTM `^GTM-[A-Z0-9]{4,12}$`. Custom snippets and the form snippet: at most 20,000 characters.
- **Dependencies:** none added. The dependency-policy test stays green.
- **Tests:** unit tests sit next to the code. Snippets are unit-tested in happy-dom by evaluating `asset.src` in the test window; real browser behavior is tested from `file://` in `tests/e2e/renderer/` with Playwright `page.route` stubs for vendor scripts and form providers. React UI is tested in `tests/e2e/app/` (serial, one owner account, pages reset).
- **Local database:** create migrations with `pnpm supabase migration new <name>`, apply with `pnpm supabase migration up --local </dev/null`, then `pnpm db:types`. Never `db:reset`.
- **Editor UI copy** is English, sentence case. Strings tests rely on are fixed in each task's UI contract. Exported pages use the page language through `lib/renderer/i18n.ts` (id and en).
- **Commits:** small conventional commits ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Run `pnpm format` (and `pnpm assets` after touching any `styles.css`, `snippet.js` or `*.bundle.ts`) before committing.

### Task 1: Unload flush during an in-flight save (M2a M3)

**Files:**
- Modify: `lib/editor/autosave.ts`, `lib/editor/autosave.test.ts`

**Interfaces:**
- Consumes: `createAutosave`, `SaveRequest`, `SaveResponse` (M2a).
- Produces: no new exports; `flush({ unloading: true })` changes behavior.

**Rules:**
- `flush({ unloading: true })` while a save is in flight no longer waits for it. If the snapshot is newer than the in-flight version, it sends a keepalive copy at once with `baseRevision = state().revision + 1` (the revision the in-flight save will create) and a fresh `saveId`, records `saveId → version` in `unanswered`, and ignores that request's answer. The status is not changed by the copy.
- The `ok` branch of `settle` removes only `unanswered` entries whose version is ≤ the version it saved (today it clears them all), so the keepalive copy stays recognizable.
- If the page survives (bfcache, a tab that comes back), the normal next save meets a 409 naming the keepalive's `saveId`, and the existing "landed" branch builds on it.
- `flush()` without `unloading` is unchanged.

```sql
-- Called from the browser as the signed-in user; inserts the version and points the page at it.
public.record_page_version(
  p_id uuid, p_page_id uuid, p_document jsonb, p_html_path text, p_export_settings jsonb,
```

**Rules (D-049):**
- **m-6:** `page_versions` gets `unique (id, page_id)`. `pages_latest_version_id_fkey` is replaced by `pages_latest_version_fkey foreign key (latest_version_id, id) references page_versions (id, page_id) on delete set null (latest_version_id)`, so a page can only point at its own versions.

It inserts the row (`kind = 'export'`), then updates the page: `latest_version_id = p_id`, and `status = 'exported'` when it was `'draft'` (other statuses stay). It raises when the update matched no row. `grant execute … to authenticated`; revoke from `public, anon`.
- **Bucket policies** on `storage.objects` for `page-versions`: members (`is_workspace_member(workspace_from_path(name))`) may insert, select and delete; there is no update policy, so stored exports are immutable.

```ts
// vendors.ts (pure; ids are already validated by the schema)
export function renderTrackingHead(tracking: TrackingSettings): SafeHtml;      // Meta base code, gtag.js + config, GTM head
export function renderTrackingBodyStart(tracking: TrackingSettings): SafeHtml; // GTM and Meta <noscript>
```

**Rules (D-047; D-019 revised):**
- **Head, export only, in this order:** charset, viewport, title, description, robots; then `og:title` (seo title, else the untitled text), `og:description` (when set), `og:type` `website`, `og:image` (only when `ogImage.src` is an absolute http(s) URL); then `<link rel="icon" href>` when the favicon `src` passes `sanitizeUrl(…, 'image')`; then `<style>`; then, when `tracking` is on, the vendor head and `headCode`.
- **Body, export with tracking on:** `<body>` gets `trackingBodyAttributes`; `renderTrackingBodyStart` comes first in `<body>`; `bodyCode` comes after the footer sections and before the page script.
- **Vendor code:**
  - Meta: the standard base code (loads `https://connect.facebook.net/en_US/fbevents.js`), `fbq('init', id)`, `fbq('track', 'PageView', {}, { eventID: <id> })`, where the event id is computed by inline code; `<noscript><img height="1" width="1" alt="" style="display:none" src="https://www.facebook.com/tr?id=<id>&ev=PageView&noscript=1"></noscript>` at the start of the body.
  - gtag: one loader `https://www.googletagmanager.com/gtag/js?id=<first of ga4Id, googleAdsId>`, then `window.dataLayer=window.dataLayer||[];function gtag(){dataLayer.push(arguments)}gtag('js',new Date());` and `gtag('config', id)` for each set id. (`new Date()` here is text the renderer emits, not a call it makes.)
  - GTM: the standard head snippet for `gtmId`, and `<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=<id>" height="0" width="0" style="display:none;visibility:hidden" title="Google Tag Manager"></iframe></noscript>`.
  - All inline code goes through `escapeInlineScript`.
- **The page runtime** (`lib/tracking/snippet.js`, ES2017, ≤ 2048 bytes minified) is included first in `collectJs` when `mode === 'export'` and the page has a CTA, a form embed or any tracking id; never in preview.
- **Runtime: events.**
  - Event id: `<Date.now() base36>-<8 random base36 chars>` (`crypto.getRandomValues` when available).
  - On `lp:track` `{ name, params }`:
    - Meta: `fbq('track', name, params, { eventID })` when `fbq` exists.
    - gtag: `gtag('event', gaName, { ...params, event_id })` when `gtag` exists, where `gaName` is `Lead` → `generate_lead`, `Contact` → `contact`, `InitiateCheckout` → `begin_checkout`, `ViewContent` → `select_item`.
    - GTM: with `data-lp-gtm`, `dataLayer.push({ event: gaName, event_id, ...params })`.
    - Google Ads: for `Lead` with `data-lp-conversion`, `gtag('event', 'conversion', { send_to, transaction_id: eventId })`.
  - A click on `[data-lp-event]` dispatches `lp:track` with that name; `renderCta` adds `data-lp-event="<event>"` when the CTA's `event` isn't `none`.
- **Runtime: passthrough.**
  - At start, read the parameters listed in Global Constraints from `location.search`, merge them over `sessionStorage['lp-params']` (every storage access in try/catch), and store the result.
  - For every `a[data-lp-cta]` whose `href` is absolute http(s), and every `iframe[data-lp-pass]` `src`, append each key the URL doesn't already have, with `encodeURIComponent`, before any `#hash`. Other parameters keep their exact text.
  - Links that aren't http(s) (`#form`, `tel:`, `mailto:`) are untouched.
- **D-019 revised:** the CTA row becomes "none by default; per CTA `Lead`, `Contact` or `InitiateCheckout`"; add the GA4/GTM names above and "Google Ads `conversion` on every `Lead` when a label is set". The carousel row stays M4.
